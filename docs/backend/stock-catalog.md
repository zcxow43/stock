# 股票清單查詢 API

提供股票清單與單檔基本資料的**唯讀查詢**，是前端股票列表頁的唯一資料來源。查詢一律讀取目前已存在資料庫中的股票主檔與最新收盤行情，不對外抓取任何資料、不做任何運算或寫入，純粹是「把庫裡已有的東西列出來看」。為了在全市場約 2200 檔的規模下維持效能，查詢採「先分頁、再取行情」的固定順序，並刻意不支援依漲跌幅排序。整支 API 沒有任何送審流程，因為它完全不異動資料。

## 欄位定義

**股票（清單列 / 單檔基本資料共用）**

| Field | Type/Role | Rule |
|---|---|---|
| stockId | 識別碼 | 股票代號，查詢鍵值 |
| stockName | 名稱 | 股票名稱，可作關鍵字搜尋比對對象 |
| market | 分類 | 市場別，僅 `TSE`／`OTC` 兩種可篩選 |
| isActive | 狀態 | 是否仍在市；預設清單僅顯示上市中股票 |
| latestTradeDate | 行情資訊 | 最近一個有行情的交易日；無行情時為空 |
| latestClose | 行情資訊 | 最新收盤價；無行情時為空，不可顯示為 0 |
| previousClose | 行情資訊 | 前一交易日收盤價；僅有一日行情時為空 |
| changeAmount / changePercent | 衍生計算值 | 由最新與前一收盤價相減／相除計算，不落地儲存 |
| latestVolume | 行情資訊 | 最新交易日成交量 |
| firstTradeDate | 彙總資訊（僅單檔） | 該檔最早有行情的交易日 |
| tradingDayCount | 彙總資訊（僅單檔） | 該檔累積有行情的交易日數 |

## 限制條件

- 分頁為必要機制，每頁筆數上限 200 筆，超過即明確拒絕，不做截斷。
- 排序欄位僅限股票自身屬性（代號／名稱／市場別），不支援依漲跌幅排序，這是刻意的取捨。
- 預設僅顯示上市中股票，已下市股票須明確要求才會出現。
- 尚無任何行情的股票仍必須出現在清單中，行情欄位以空值表示，不得隱藏或以 0 表示。
- 關鍵字搜尋同時比對代號與名稱，任一命中即列入結果。

## 跨主題規則

- 股票主檔與每日行情資料，皆由每日排程抓取維護，本功能只負責讀取，不負責回補（見 stock-price-ingestion.md）。
- 已下市股票的歷史行情仍會保留，僅在日常瀏覽清單中被過濾，實際資料仍完整存在（見 stock-price-ingestion.md）。

## API 清單
| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/stocks | 查詢股票清單（含篩選、搜尋、分頁與最新行情） | Live direct |
| GET | /api/stocks/{stockId} | 查詢單一股票的基本資料與行情彙總 | Live direct |
