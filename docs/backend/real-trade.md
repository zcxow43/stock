# 真實交易持股 API

這組 API 用來記錄使用者本人實際持有的部位，並即時算出到今天為止的未實現損益。它和模擬交易是同一個功能的兩份資料：端點形狀、回應欄位、交易成本算法與排序規則都相同。差別有兩點——真實交易存在一份隨程式碼版控的 CSV 檔而不是資料庫；買進價與股數由使用者指定，不由系統推算。查詢一律讀檔後即時算出現價與損益，檔案內容有問題的行會被略過並逐行回報，不會讓整份清單失敗。新增與刪除沒有審核流程，成功就直接改寫該檔，只有欄位名列壞掉時才會拒絕並完全不動檔案。

## 欄位定義

**真實交易持股（`data/real-trades.csv` 中的一筆部位）**

| Field | Type/Role | Rule |
|---|---|---|
| stockId | 股票代號 | 必填；前後空白去除；新增時須存在於股票主檔（不論是否仍在交易中） |
| buyDate | 實際成交日（YYYY-MM-DD） | 必填；不得晚於今日；不要求該日在庫中有行情 |
| buyPrice | 實際成交價（每股） | 必填；須大於 `0`；最多兩位小數；由使用者給，不取收盤價，也不以收盤價覆蓋 |
| shares | 股數（不是張數，1 張 = 1,000 股） | 必填；須為大於 `0` 的整數 |
| id | 資料行序號（唯讀，非儲存值） | 依檔案中的資料行順序從 `1` 起算；欄位名列、空白行、註解行與被略過的壞行都不佔序號；刪除後其餘各筆序號前移，因此只供一次「查詢→刪除」來回使用 |
| 即時計算結果 | 唯讀，回應中附帶 | 買進手續費、成本、現價日、現價、賣出手續費、證交稅、未實現損益、報酬率；現價日為「今日（含）以前、收盤價大於 `0` 的最近一個交易日」；查不到現價時只有買進手續費與成本有值，其餘皆為空 |

## 限制條件

- 儲存位置固定為專案根目錄下的 `data/real-trades.csv`，UTF-8（不含 BOM）、換行 LF，隨程式碼進版控。
- 第一行欄位名列必須逐字等於 `stockId,buyDate,buyPrice,shares`；不符時查詢、新增、刪除全部拒絕（500），且新增與刪除完全不動檔案。
- 不新增任何資料表或欄位；資料庫只讀股票主檔與日線行情，不寫入。
- 不建立任何上傳、OCR、圖片解析或匯入端點；資料進入 CSV 的方式（手工編輯或 AI 助理代填）發生在程式之外。
- 四個輸入欄位全部必填，沒有任何預設值，系統不替使用者猜值。
- 不做「同檔同日」唯一性檢查，因此沒有衝突錯誤；同檔同日可有多筆（分批成交），每筆各自計算損益，不合併、不加權平均。
- 刪除一律以 `id`（資料行序號）指定；`id` 不是正整數或超出目前資料行數時回「找不到」（404），不做猜測。刪除沒有其他前置限制，成功即直接移除該行。
- 檔案不存在時：查詢視同空清單（不是錯誤）；新增會建立檔案並寫入欄位名列與第一筆。
- 只有欄位名列、沒有資料行是合法狀態，查詢回空清單。
- 空白行略過；以 `#` 開頭的行視為註解並略過。
- 格式錯誤的行（欄位數不是 4、買進日非法或晚於今日、買進價不合規、股數不合規）逐行略過並列在 `skippedLines`（含檔案實際行號與原始內容），不佔 `id`、不計入任何總計。
- 新增與刪除都是整檔改寫：欄位名列、註解行、空白行與被略過的壞行全部原樣保留在原來的相對位置；寫入先寫暫存檔再原子換名，避免留下截斷的檔案。
- 查不到現價的那筆照常列出，成本計入總成本，但不計入未實現損益總計與總報酬率；總報酬率的分母只含有現價的那幾筆。
- 股票不在主檔時，股票名稱為空，其餘處置同「查不到現價」，整個查詢不失敗。
- 現價日等於買進日時未實現損益必為負（只付出成本），不得夾為 `0`。
- 排序由本 API 決定：買進日由新到舊，同日依股票代號升冪，再同則依 `id` 升冪。
- 沒有任何持股時仍回成功，兩個總額為 `0`、總報酬率為空。
- 新增的回應是「剛才建立了什麼」的回執；排序、總計與其他各筆的 `id` 一律以重新查詢為準。

## 跨主題規則

- 成本與損益的算法（手續費率 0.1425%，買進、賣出各一次，不打折、不設最低；證交稅 0.3% 只在賣出時收；三項各自無條件捨去至整數元；報酬率四捨五入至兩位小數）與模擬交易共用同一份定義與實作，同樣的買進價、股數、現價兩邊算出的結果逐位相同（見 [simulated-trade.md](simulated-trade.md)）。
- 同一功能的兩份資料：端點形狀、回應欄位與排序規則與模擬交易一致，但不採用模擬交易「同檔同日唯一」的限制，也不由系統填入買進價與股數（見 [simulated-trade.md](simulated-trade.md)）。
- 新增時股票代號是否有效、以及清單上顯示的股票名稱，都取自股票主檔；主檔查不到時新增會被拒絕（400），但已在檔案裡的舊紀錄只是名稱留空，不會讓清單失敗（見 [stock-catalog.md](stock-catalog.md)）。
- 現價取自既有日線行情中「收盤價大於 `0` 的最近交易日」；本 API 只讀不寫，也不要求買進日在庫中有行情（見 [stock-price-ingestion.md](stock-price-ingestion.md)）。

## API 清單

| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | `/api/real-trades` | 列出目前所有持有部位，並即時算出現價、未實現損益、各項總計與被略過的壞行 | Live direct |
| POST | `/api/real-trades` | 新增一筆使用者指定買進日、價格與股數的持有部位，立即寫入 CSV 並回傳該筆含損益的回執（201） | Direct |
| DELETE | `/api/real-trades/{id}` | 依資料行序號刪除一筆持有部位，立即從 CSV 移除（204） | Direct |
