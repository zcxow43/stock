# 真實交易 API

這組 API 記錄使用者本人實際持有的部位，並即時算出到今天為止的未實現損益。它和模擬交易是同一個功能的兩份資料，端點形狀、回應內容、交易成本算法和排序規則都相同；差別有兩點——資料存在一份隨程式碼版控的 CSV 檔而不在資料庫，以及買進價與股數由使用者指定、不由系統填入。查詢一律讀取檔案目前的內容，並即時對照最新行情算出現價與損益，不存放算好的結果。新增、修改、刪除都不需要送審，直接整檔改寫該檔，同時保留使用者手寫的註解、空白行與尚未改好的錯誤行。檔案由使用者手工維護，所以格式錯誤的資料行只會被略過並列在回應裡，不會讓整份清單失敗。

## 欄位定義

**真實交易（CSV 中的一筆持有部位）**

| Field | Type/Role | Rule |
|---|---|---|
| id | 整數／識別 | 不存在檔案裡。它是這筆在資料行中的位置，從 1 起算；欄位名列、空白行、註解行、被略過的錯誤行都不佔序號。刪除後其後各筆會往前移，所以只在一次查詢到刪除或修改的來回內可靠。 |
| stockId | 字串／必填 | 股票代號。新增時前後空白會先去除，且必須存在於股票主檔，不論該檔是否仍在交易。 |
| stockName | 字串或空／回報用 | 取自股票主檔。主檔查不到時為空，該筆仍正常回報。 |
| buyDate | 日期／必填 | 實際成交日，格式 YYYY-MM-DD，不得晚於今日（台北日曆日）。不要求該日在行情庫中有收盤價。 |
| buyPrice | 數值／必填 | 使用者的實際成交價（每股），須大於 0、最多兩位小數。原樣取自檔案，不以行情收盤價覆蓋。 |
| shares | 整數／必填 | 股數，不是張數（1 張 = 1,000 股），須大於 0。 |
| excluded | 布林／選填 | true 表示該筆不計入三個總計；true／false 不分大小寫，空值視為 false。這是可逆的統計設定，不是刪除。 |
| targetSellPrice | 數值或空／選填 | 使用者自填的每股目標賣價，須大於 0、最多兩位小數，空值表示未設定。只記錄與回報，不參與任何計算、比較或排序。 |
| buyFee | 整數（元）／回報用 | 買進手續費，費率 0.1425%，無條件捨去至整數元。一律有值。 |
| cost | 整數（元）／回報用 | 買進價 × 股數 ＋ 買進手續費。一律有值，與有無現價無關。 |
| currentDate | 日期或空／回報用 | 現價日：該檔今日（含）以前、收盤價大於 0 的最近一個交易日。可能早於今日，查不到現價時為空。 |
| currentPrice | 數值或空／回報用 | 現價日的收盤價，查不到時為空。 |
| sellFee | 整數或空（元）／回報用 | 假設以現價賣出的手續費，費率 0.1425%，無條件捨去。查不到現價時為空。 |
| sellTax | 整數或空（元）／回報用 | 假設以現價賣出的證交稅，稅率 0.3%，無條件捨去。查不到現價時為空。 |
| unrealizedProfit | 整數或空（元）／回報用 | 現價 × 股數 − 賣出手續費 − 證交稅 − 成本。可為負；現價日等於買進日時必為負，不得夾為 0。查不到現價時為空。 |
| returnPercent | 數值或空／回報用 | 未實現損益 ÷ 成本 × 100，四捨五入至小數第二位，可為負。查不到現價時為空。 |

**彙總與略過行（查詢回應的附帶內容）**

| Field | Type/Role | Rule |
|---|---|---|
| asOfDate | 日期 | 本次查詢的今日（台北日曆日）。同時是畫面上買進日輸入的預設值與可選上限。 |
| feeRatePercent／taxRatePercent | 數值 | 恆為 0.1425 與 0.3，供畫面說明扣了哪些成本。 |
| totalCost | 數值 | 只加總「有統計」各筆的成本；無持股或全部被排除時為 0。 |
| totalUnrealizedProfit | 數值 | 只加總「有統計且有現價」各筆的未實現損益；沒有這樣的筆時為 0。 |
| totalReturnPercent | 數值或空 | 總未實現損益 ÷「有統計且有現價」各筆成本合計 × 100，兩位小數。沒有任何一筆同時有統計且有現價時為空。分母與分子涵蓋同一批筆，避免報酬率被無故稀釋。 |
| skippedLines[].lineNumber | 整數 | 被略過行在檔案中的實際行號，含欄位名列，從 1 起算。 |
| skippedLines[].content | 字串 | 該行原始內容，原樣回報，方便使用者直接跳去修改。 |

## 限制條件

- 只有「不統計」與「目標賣價」兩項可修改。代號、買進日、買進價、股數一旦寫入就不能由 API 修改，要改只能刪除重加，或直接編輯資料檔；修改請求帶了這四項也一律不生效。
- 新增時四個欄位（代號、買進日、買進價、股數）全部必填，沒有任何預設值，系統不替使用者猜測。
- 新增時不接受「不統計」與「目標賣價」。新寫入的一筆一律是統計中、目標賣價未設定，之後再用修改功能設定。
- 同一檔同一天可以有多筆，不檢查重複，也不會因重複而拒絕（沒有 409）。每一筆各自計算損益，不合併、不加權平均。
- 刪除是真的從檔案中移除該行。刪除的編號不存在或超出目前資料行數時，拒絕並說明找不到（404），不做猜測。
- 修改時若兩個欄位都沒給，不算錯誤：回傳該筆現狀，且不改寫檔案。給了「目標賣價」但明確填空值，代表清除已設定的目標賣價；省略則維持原值。
- 被標為「不統計」的筆仍會出現在清單中，自己的各項數字照常計算，只是不計入三個總計。
- 目標賣價不影響成本、損益、報酬率、任何總計或排序，也不與現價比較。
- 查不到現價的筆，現價與損益相關欄位為空，但買進手續費與成本照常有值。該筆（在統計中時）計入總成本，不計入總損益與總報酬率。
- 股票代號在主檔查不到時，只是名稱為空，不會讓整份清單失敗。
- 清單排序固定由新到舊（買進日），同日依股票代號升冪，再同則依檔案先後；畫面不重排。
- 沒有任何持股時仍正常回應：清單為空，兩個總額為 0，總報酬率為空。
- 檔案不存在時，查詢視同空清單；新增時才會建立該檔。
- 欄位名列必須是現行六欄格式或舊的四欄格式，否則查詢、新增、修改、刪除都拒絕（500），且不寫入檔案，避免靜默改壞使用者手寫的內容。舊四欄格式仍可讀取，會在下一次寫入時自動升級為六欄。
- 資料行欄位數 4、5、6 皆合法，缺少的尾欄視為預設（統計中、目標賣價空）。
- 格式錯誤的資料行逐行處理：略過、列入略過清單、不佔編號、不計入總計，其餘各行照常回報。
- 每次寫入都是整檔改寫：欄位名列升級為六欄，各行保留原有欄位的字面內容（`1140.00` 不會變成 `1140.0`），只補足缺少的尾欄。註解行、空白行與被略過的錯誤行原樣保留在原位置。寫入採先寫暫存檔再原子換名，避免中斷後留下殘缺檔案。
- 不新增任何資料表或資料庫欄位；對資料庫只讀取股票主檔與每日行情。
- 不提供上傳、圖片辨識或匯入的功能；資料如何進入檔案（手工編輯、請 AI 助理代填）發生在程式之外。
- 編號只在「查詢後立刻刪除或修改」的來回內穩定，所以畫面在每次新增、修改、刪除成功後都要重新取得清單。
- 新增、修改、刪除的驗證失敗，一律以明確的錯誤代碼說明原因：代號缺漏或不存在、買進日缺漏或晚於今日、買進價或股數不合規、目標賣價不合規、請求本體無法解析。

## 跨主題規則

- 成本與損益的算法（現價日取法、手續費與證交稅各自獨立無條件捨去、報酬率四捨五入、現價日等於買進日時損益必為負）與模擬交易共用同一份實作，同一組買進價、股數、現價在兩邊算出的結果逐位相同；排序規則與回應欄位形狀也和模擬交易一致（見 [simulated-trade.md](simulated-trade.md)）。
- 模擬交易的買進價由系統取當日收盤、股數固定 1,000，因此同檔同日必須唯一；真實交易的價格由使用者指定，所以不做同檔同日的唯一性限制（見 [simulated-trade.md](simulated-trade.md)）。
- 查詢時要用批次方式取得股票名稱與現價，不可逐筆往返查詢，與模擬交易既有的批次做法一致（見 [simulated-trade.md](simulated-trade.md)）。
- 新增時股票代號必須存在於股票主檔（不論是否仍在交易）；查詢時主檔查不到只讓名稱為空，不讓清單失敗（見 [stock-catalog.md](stock-catalog.md)）。
- 畫面在每次新增、修改、刪除成功後一律重新取得清單，因為排序、總計與其餘各筆編號都由查詢決定（見 [真實交易分頁](../frontend/real-trade.md)）。

## API 清單

| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/real-trades | 讀取資料檔內所有持有部位，即時對照最新行情算出現價、未實現損益與三個總計，並列出被略過的錯誤行 | Live direct |
| POST | /api/real-trades | 新增一筆使用者實際成交的持有部位，立即寫入資料檔並回傳剛建立的那筆 | Direct |
| PATCH | /api/real-trades/{id} | 修改某一筆的「不統計」與「目標賣價」，立即寫入資料檔並回傳修改後的該筆 | Direct |
| DELETE | /api/real-trades/{id} | 從資料檔移除某一筆持有部位，立即生效 | Direct |
