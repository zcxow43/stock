# 模擬交易持股 API

這支 API 讓使用者用最少的輸入（股票代號，加上選填的買進日）記下「假設我在那天買了一張，到現在賺賠多少」。持股只記錄買了什麼、哪天買、買進價多少；未實現損益、報酬率與現價都在每次查詢當下，依最新收盤價即時算出，不會儲存。建立、刪除持股都是直接生效，沒有送審或核准流程，也不會抓取任何外部資料，只讀取系統已有的行情與股票名稱。買進價不是使用者填的數字，而是系統從買進日的實際行情取得（預設收盤價，策略分頁「加入模擬」可改取開盤價）。查詢時可另外指定「目標結算日」，系統會多回報一份以買進日到該日之間最高價賣出的結算結果，與以現價計算的結果並列。

## 欄位定義

**模擬持股（一筆）**

| Field | Type/Role | Rule |
|---|---|---|
| 識別碼（id） | 整數／系統產生 | 刪除時用來指定這一筆。 |
| 股票代號（stockId） | 字串／建立時輸入 | 必填；前後空白去除後比對；必須是股票清單中已存在的代號；已下市的股票也可加入。 |
| 股票名稱（stockName） | 字串／唯讀 | 取自股票清單，不由使用者輸入。 |
| 買進日（buyDate） | 日期／建立時選填 | 省略時取該檔最後一個有收盤價的交易日；不得晚於今日；該檔在那天必須有可用價格，否則拒絕，不會自動改用鄰近交易日。 |
| 買進價計價基準（priceBasis） | 字串／建立時選填 | 只能是「收盤價」或「開盤價」，省略視為收盤價；選開盤價時必須同時指定買進日。 |
| 買進價（buyPrice） | 數字／系統取得 | 使用者不能輸入；取自買進日該檔的收盤價或開盤價，且必須大於 0；寫入後不再變動。 |
| 股數（shares） | 整數／固定值 | 恆為 1000（1 張），不可指定。 |
| 買進手續費（buyFee） | 整數（元）／計算值 | 買進價 × 股數 × 0.1425%，無條件捨去至元。 |
| 成本（cost） | 整數（元）／計算值 | 買進價 × 股數 ＋ 買進手續費。 |
| 現價日（currentDate） | 日期／計算值 | 該檔今日以前最後一個有收盤價（大於 0）的交易日；可能早於今日（假日或已下市）。 |
| 現價（currentPrice） | 數字／計算值 | 現價日的收盤價。 |
| 賣出手續費（sellFee） | 整數（元）／計算值 | 以現價估算的賣出手續費（0.1425%），無條件捨去至元。 |
| 證交稅（sellTax） | 整數（元）／計算值 | 以現價估算的證交稅（0.3%，只在賣出時），無條件捨去至元。 |
| 未實現損益（unrealizedProfit） | 整數（元）／計算值 | 現價 × 股數 − 賣出手續費 − 證交稅 − 成本；可為負，不夾為 0；現價日等於買進日時必為負。 |
| 報酬率（returnPercent） | 數字（%）／計算值 | 未實現損益 ÷ 成本 × 100，四捨五入至小數第二位；可為負。 |
| 結算（settlement） | 物件或空值／計算值 | 只在查詢帶目標結算日、且買進日不晚於該日時才有；否則為空。 |

**結算內容（settlement，隨目標結算日產生）**

| Field | Type/Role | Rule |
|---|---|---|
| 賣出日（sellDate） | 日期／計算值 | 結算窗口內最高價第一次出現的交易日。 |
| 賣出價（sellPrice） | 數字／計算值 | 買進日起至目標結算日止（含兩端）、最高價大於 0 的各日中最大的最高價。 |
| 賣出手續費（sellFee）、證交稅（sellTax） | 整數（元）／計算值 | 以賣出價計，與現價口徑同一套交易成本，各自無條件捨去至元。 |
| 結算損益（profit） | 整數（元）／計算值 | 賣出價 × 股數 − 賣出手續費 − 證交稅 − 成本；可為負，不夾為 0。 |
| 結算報酬率（returnPercent） | 數字（%）／計算值 | 結算損益 ÷ 成本 × 100，兩位小數；可為負。 |

**列表彙總（隨查詢回報）**

| Field | Type/Role | Rule |
|---|---|---|
| 查詢日（asOfDate） | 日期／計算值 | 本次查詢的今日（台北日曆日）。 |
| 預設買進日（defaultBuyDate） | 日期或空值／計算值 | 全市場上一次收盤日，供畫面當日期預設值；不是某一檔的最後交易日；資料庫完全沒有行情時為空。 |
| 每筆股數、手續費率、證交稅率（lotSize／feeRatePercent／taxRatePercent） | 固定值 | 恆為 1000、0.1425、0.3，供畫面說明扣了什麼。 |
| 總成本（totalCost） | 數字／計算值 | 各筆成本總和；無持股時為 0。 |
| 總未實現損益（totalUnrealizedProfit） | 數字／計算值 | 各筆未實現損益總和；無持股時為 0。 |
| 總報酬率（totalReturnPercent） | 數字或空值／計算值 | 總未實現損益 ÷ 總成本 × 100（成本加權，不是各檔報酬率的算術平均）；無持股時為空而不是 0。 |
| 目標結算日（settleDate） | 日期或空值／查詢參數 | 原樣帶回；未帶時為空。 |
| 結算總成本、結算總損益（settledTotalCost／settledTotalProfit） | 數字／計算值 | 只加總有結算的各筆；沒有任何一筆有結算時為 0。 |
| 結算總報酬率（settledTotalReturnPercent） | 數字或空值／計算值 | 結算總損益 ÷ 結算總成本 × 100（成本加權）；沒有任何一筆有結算時為空。 |

## 限制條件
- 買進價與股數不可由使用者輸入；要換價格就換買進日。
- 買進價寫入後不再變動，即使該日收盤價事後被行情來源更正，成本也不變。
- 買進日不得晚於今日；格式不合法同樣拒絕。
- 指定的買進日該檔必須正好有所取的價格（收盤價或開盤價）；停牌、尚未上市、無該日資料、或價格為 0 都拒絕，不會自動改用鄰近交易日。
- 計價基準只能是「收盤價」或「開盤價」；選開盤價時必須同時帶買進日。
- 省略買進日時，該檔若完全沒有任何收盤價大於 0 的交易日，則拒絕。
- 股票代號不可為空，且必須存在於股票清單，否則拒絕並列出不認得的代號。
- 同一檔股票在同一個買進日只能有一筆；重複加入一律拒絕（409），不會覆蓋，與計價基準無關。
- 刪除不存在的持股回「找不到」（404）；刪除成功無內容回傳（204）。
- 目標結算日不得晚於今日，格式不合法同樣拒絕。
- 買進日晚於目標結算日的持股沒有結算：照常列出、照常計入現價相關總計，但不計入結算總計。
- 目標結算日晚於該檔最後交易日時，結算窗口只到該檔最後有行情的日子，照常結算，不報錯。
- 已下市的股票照常列出並計入彙總，現價為其最後一個有成交日的收盤價。
- 目標結算日只是一次查詢的參數，不會被儲存。
- 列表排序固定：買進日由新到舊，同日依股票代號由小到大；沒有任何持股時仍正常回應（空清單），不算錯誤。
- 三支端點都不抓取外部資料，也不會改動股票清單或行情資料。

## 跨主題規則
- 持股記錄存放於模擬交易資料表，買進價寫入後不再變動的理由，由該資料表的規格說明（見 specs/dba/simulated-trade.md）。
- 現價、買進價、結算賣出價全部讀取已入庫的每日行情，本模組不自行抓取行情；收盤價為 0 的日子視為「該日沒有成交」，不當作行情（見 stock-price-ingestion.md、strategy-backtest.md）。
- 股票名稱與「代號是否存在」取自股票清單，已下市的股票也算存在、不排除（見 stock-catalog.md）。
- 交易成本（買賣手續費各 0.1425%、賣出證交稅 0.3%、三項各自無條件捨去至元、每筆固定 1 張）與策略回測完全同一套，不另立定義；差別只在出場假設：回測用區間最高開盤價，本模組預設用現價，帶目標結算日時另報最高價結算（見 strategy-backtest.md）。
- 策略分頁命中彙總表的「加入模擬」會送出「取開盤價」的買進價計價基準，使持股買進價與回測買進價是同一個數字（見 strategy-backtest.md、specs/frontend/strategy.md）。
- 「不認得的股票代號」的錯誤代碼與回應形狀，沿用策略掃描已定的同名錯誤（見 strategy-scan.md）。
- 不篩選是否已下市的原則與策略回測一致（見 strategy-backtest.md）。
- 預設買進日、現價日、現價與結算的顯示方式，由模擬交易畫面決定（見 specs/frontend/simulated-trade.md）。

## API 清單
| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/simulated-trades | 查詢所有模擬持股的現價、未實現損益與彙總，可選帶目標結算日一併回報最高價結算結果 | Live direct |
| POST | /api/simulated-trades | 以股票代號（與選填的買進日、計價基準）建立一筆模擬持股，買進價由系統依當日行情決定 | Direct |
| DELETE | /api/simulated-trades/{id} | 刪除單筆模擬持股 | Direct |
