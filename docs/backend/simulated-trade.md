# 模擬交易持股 API

本功能讓使用者以「股票代號＋（可選的）買進日」快速建立一筆假設持股，系統以該日的實際收盤價當作買進成本、固定以一張（1000 股）計算。查詢時，未實現損益、報酬率與現價一律**即時計算、不落地儲存**，隨每日最新收盤價變動；買進當下寫入的買進日、買進價與股數則永久保留、之後不再改變。整套功能是單純的資料查詢與建立/刪除，沒有審核流程，任何成功的請求都會直接生效，不存在「送審後才生效」的中間狀態。

## 欄位定義

**模擬交易持股（simulated_trade）**

| Field | Type/Role | Rule |
|---|---|---|
| id | 識別碼，系統產生 | 建立時配發；刪除、辨識單筆持股皆以此為準 |
| stockId | 股票代號（持股欄位，寫入後不變） | 必填；去除前後空白後比對；須存在於股票主檔（不論是否已下市） |
| buyDate | 買進日（持股欄位，寫入後不變） | 可由使用者指定，不得晚於今日；省略時取該檔最後一個有收盤價的交易日；同一檔同一買進日只能存在一筆 |
| buyPrice | 買進價（持股欄位，寫入後不變） | 取自該檔買進日當天的收盤價，且該價格須大於 0；一旦寫入，即使該日收盤價事後被來源更正也不重新計算 |
| shares | 股數（持股欄位） | 固定為 1000（一張），使用者不可指定，也不可事後修改 |
| currentDate | 現價日（每次查詢即時計算，不落地） | 該檔小於等於今日、且有收盤價的最新交易日；可能早於今日（例如已下市或遇假日） |
| currentPrice | 現價（即時計算） | 現價日當天的收盤價 |
| buyFee / sellFee / sellTax / cost | 交易成本（即時計算） | 依買進價／現價、固定手續費率與證交稅率算出，各項金額各自無條件捨去至整數元 |
| unrealizedProfit | 未實現損益（即時計算） | 以現價估算「假設今天賣掉」的損益，可為負值，剛買進當天必為負值屬正常結果 |
| returnPercent | 報酬率（即時計算） | 未實現損益除以成本後取百分比，四捨五入至小數第二位，可為負值 |
| defaultBuyDate | 預設買進日（列表層級，即時計算） | 全市場最後一個有收盤價的交易日，供畫面當作日期輸入的預設值；資料庫完全沒有行情時為空 |

## 限制條件

- 買進日不得晚於今日；今日本身可選，但僅在今日收盤價已經存在時才成立。
- 買進日當天必須確實存在該檔的收盤價（非缺漏、非 0），否則拒絕建立；系統不會自動往前找最近的交易日代替使用者指定的日期。
- 股數固定為一張（1000 股），不接受使用者自訂。
- 買進價一經寫入即永久固定，不隨後續收盤價的更正而重新計算。
- 同一檔股票、同一買進日只能存在一筆持股，重複建立會被拒絕（視為「已經加過」而非「輸入錯誤」，回應以 409 表示）。
- 已下市的股票仍照常回報、照常計入彙總，不會被排除在列表或總計之外。
- 刪除以識別碼為準，識別碼不存在時視為失敗，不會刪錯或靜默忽略。
- 列表回應所帶的「全市場預設買進日」，取的是全市場層級最後一個有收盤價的交易日，與個別股票各自的最後交易日無關；資料庫完全沒有任何收盤價時，此值為空。
- 沒有任何持股時仍為正常查詢結果（非錯誤）：清單為空、兩個總額為 0、總報酬率為空值。

## 跨主題規則

- 建立持股時，代號必須存在於股票主檔（不論是否已下市）才算合法，否則視為「代號不存在」而非其他錯誤（見 stock-catalog.md）。
- 買進價、現價與全市場預設買進日全部讀自股票每日收盤價資料；若某日尚未寫入收盤價、或當天收盤價為 0（代表當日無成交），都會導致建立失敗或影響現價的判定（見 stock-price-ingestion.md）。
- 未實現損益使用的交易成本規則（手續費率、證交稅率、金額捨去方式）與策略回測功能完全共用同一套定義，不另立一份，以避免畫面上兩種口徑對不上（見 strategy-backtest.md）。
- 代號不存在的錯誤沿用策略掃描已定的同名錯誤代碼與回應形狀，讓同一個畫面上的兩支端點對同一種錯誤只需一套處理（見 strategy-scan.md）。

## 錯誤情形

| 情形 | 狀態碼 | 代碼 |
|---|---|---|
| 代號缺漏或去除空白後為空 | 400 | `INVALID_STOCK_ID` |
| 代號不存在於股票主檔 | 400 | `UNKNOWN_STOCK_ID` |
| 省略買進日，但該檔今日以前完全沒有任何有成交的交易日 | 400 | `NO_PRICE_BEFORE_TODAY` |
| 買進日格式不合法，或晚於今日 | 400 | `INVALID_BUY_DATE` |
| 指定的買進日該檔沒有收盤價（無該日資料或當日無成交） | 400 | `NO_PRICE_ON_BUY_DATE` |
| 同一檔、同一買進日已經存在一筆持股 | 409 | `DUPLICATE_SIMULATED_TRADE` |
| 刪除時識別碼不存在 | 404 | `SIMULATED_TRADE_NOT_FOUND` |

## API 清單

| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/simulated-trades | 查詢目前所有模擬持股，含每筆即時計算的現價、未實現損益、報酬率，以及彙總總成本、總未實現損益、總報酬率與全市場預設買進日 | Direct |
| POST | /api/simulated-trades | 以代號與（選填的）買進日建立一筆模擬持股，成功後立即生效並回報系統實際選用的買進日與買進價 | Direct |
| DELETE | /api/simulated-trades/{id} | 刪除單筆模擬持股 | Direct |
