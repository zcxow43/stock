# 模擬交易持股 API

這組 API 讓使用者輸入股票代號和選填的買進日，記下「假設我在那天買了一張」的模擬持股。買進價由系統從當天的實際行情取得，使用者不能自己填價格。查詢時，系統一律讀取目前生效的最新行情，即時算出每筆的現價、未實現損益和報酬率，這些結果不會存起來。查詢時可以指定「目標結算日」，系統會多回報一份「在那一天以該檔當天最高價賣出」的結算結果。目標結算日若不是交易日，會自動改成距離它最近的交易日。新增和刪除都立即生效，不需審核。這組 API 不抓取外部資料，也不判定型態，只做四則運算。

## 欄位定義

**模擬持股（建立後寫入，之後不再變動）**

| Field | Type/Role | Rule |
|---|---|---|
| 識別碼 | 系統產生的編號 | 刪除時用來指定哪一筆。 |
| 股票代號 | 文字，必填 | 前後空白去除後比對，必須是股票清單中已存在的代號。已下市的股票也可以。 |
| 買進日 | 日期，選填 | 不得晚於今日，且該檔當天必須有可用的價格。省略時，取該檔最後一個有收盤價的交易日。 |
| 價格基準 | `CLOSE` 或 `OPEN`，選填 | 省略時視為 `CLOSE`（收盤價）。`OPEN`（開盤價）必須同時指定買進日。 |
| 買進價 | 系統取得，使用者不可填 | 依價格基準取買進日當天的收盤價或開盤價，必須大於 0。寫入後即使來源事後更正也不變動。 |
| 股數 | 固定 1000（1 張） | 使用者不可指定。 |

**結算結果（僅在查詢帶目標結算日時即時算出，不存起來）**

| Field | Type/Role | Rule |
|---|---|---|
| 目標結算日 | 日期，查詢參數，選填 | 不得晚於今日。非交易日時改為最近的交易日，回應回報改過後的日期。 |
| 賣出日 | 日期，系統決定 | 目標結算日當天。該檔當天沒有行情時，改用之前最後一個有行情的交易日。 |
| 賣出價 | 數字，系統決定 | 該檔在賣出日的最高價，不取區間內的最高價。 |
| 結算損益／結算報酬率 | 整數／兩位小數 | 扣除買進手續費、賣出手續費、證交稅之後的結果，可為負值。 |
| 結算總計 | 彙總 | 只加總有結算的持股，依成本加權。沒有任何一筆有結算時，總報酬率為空值。 |

## 限制條件
- 買進價和股數不可由使用者輸入。要換價格只能換買進日。
- 買進價寫入後不再變動。
- 買進日不得晚於今日。
- 買進日當天該檔必須正好有可用價格。停牌、尚未上市、價格為 0 都會被拒絕，系統不會自動改用鄰近交易日。
- 價格基準為 `OPEN` 時必須指定買進日。
- 同一檔股票在同一天只能有一筆持股。重複新增會被拒絕（409），也不會覆蓋原有那一筆。
- 刪除時，指定的持股必須存在，否則回報找不到（404）。
- 目標結算日不得晚於今日，格式也必須合法。這項檢查針對使用者原本送出的日期，先驗證，再換成交易日。
- 買進日晚於目標結算日的持股沒有結算，也不計入結算總計，但仍會列在清單中，並照常計入以現價計算的總計。
- 清單依買進日由新到舊排序，同日依股票代號由小到大，排序由後端決定。
- 沒有任何持股時，清單回傳成功（200），內容為空，總報酬率為空值而不是 0。
- 已下市的股票照常列出並計入彙總，現價取它最後一個有成交的交易日。
- 現價日等於買進日時，未實現損益必為負（只付出成本），不得改成 0。
- 帶了目標結算日，現價和結算兩組結果同時回報，結算不取代現價。
- 不帶目標結算日時，結算相關欄位為空值或 0。
- 目標結算日不會寫入任何資料。

## 跨主題規則
- 手續費率 0.1425%、證交稅 0.3%、三項各自無條件捨去至元，與策略回測使用同一套交易成本定義，不另立一份。賣出端以現價（或結算賣出價）估算（見 strategy-backtest.md）。
- 價格基準為 `OPEN` 時，買進價必須等於策略回測在同一天回報的買進價（開盤價）。策略分頁的「加入模擬」依此建立持股（見 strategy-backtest.md）。
- 股票代號必須存在於股票清單，名稱取自股票清單，已下市的股票不被排除（見 stock-catalog.md）。
- 找不到股票代號時，沿用策略掃描已定的同名錯誤碼和回應形狀（見 strategy-scan.md）。
- 現價、買進價、最高價和「全市場最後一個交易日」都讀取已入庫的每日行情，本 API 不自行抓取外部資料。價格為 0 表示「該日沒有成交」，不當作行情（見 stock-price-ingestion.md）。

## API 清單
| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/simulated-trades | 查詢所有模擬持股，含即時現價、未實現損益、彙總、預設買進日。可帶目標結算日以取得結算結果。 | Live direct |
| POST | /api/simulated-trades | 以代號和選填的買進日、價格基準新增一筆模擬持股。 | Direct |
| DELETE | /api/simulated-trades/{id} | 刪除指定的一筆模擬持股。 | Direct |
