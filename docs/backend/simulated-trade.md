# 模擬交易持股 API

這組 API 讓使用者記下「假設我在某天買了一張」的模擬持股，並查看到目前為止賺賠多少。建立持股時，買進價一律由系統讀取該日的實際行情，使用者不能自己填價格。建立時可以指定買進日。也可以只給一個起算日，由系統找出該檔在這天（含）以後的第一個交易日。查詢時一律即時計算，持股的損益與報酬率都以最新收盤價現算，不另外存放。查詢時也可以帶「目標結算日」，系統會另外算出「該日以開盤價全部賣出」的結算結果。這組 API 都不會取得外部資料，也不經過審核流程，建立與刪除都會立刻生效。

## 欄位定義

**模擬持股（建立時寫入的資料）**

| Field | Type/Role | Rule |
|---|---|---|
| 持股識別碼 | 系統產生的識別碼 | 由系統配發，刪除時用來指定是哪一筆。 |
| 股票代號 | 文字，必填 | 前後空白會先去除，必須是目錄中已存在的股票，已下市的股票也可以。 |
| 買進日 | 日期 | 由系統決定。帶「指定買進日」時就是該日。帶「起算日」時是該檔在起算日（含）以後、不晚於今日、所取價格大於 0 的第一個交易日。兩者都不帶時是該檔最後一個有收盤價的交易日。寫入後不再變動。 |
| 買進價 | 數字 | 由系統讀取買進日的收盤價或開盤價，使用者不能輸入。寫入後不再變動，即使來源事後更正該日收盤價也不跟著改。 |
| 股數 | 整數 | 固定 1000 股（1 張），不可指定。 |

**建立請求（使用者可帶的欄位）**

| Field | Type/Role | Rule |
|---|---|---|
| 股票代號 | 文字，必填 | 不可為空，且須存在於股票目錄。 |
| 指定買進日 | 日期，選填 | 不得晚於今日，該檔該日必須有所取價格（大於 0）。不會自動改用鄰近交易日。 |
| 起算日 | 日期，選填 | 與「指定買進日」二擇一，不可同時帶。可以不是交易日，系統會往後找該檔的第一個交易日。晚於今日時視為還沒有行情，不視為格式錯誤。 |
| 價格基準 | 選項，選填 | 收盤價（預設）或開盤價。選開盤價時，必須同時帶指定買進日或起算日。 |

**列表回應（彙總層）**

| Field | Type/Role | Rule |
|---|---|---|
| 今日 | 日期 | 本次查詢當下的台北日曆日。 |
| 預設買進日 | 日期或空值 | 全市場上一次收盤日，供畫面當預設值，與個別股票無關。資料庫完全沒有行情時為空值。 |
| 每筆股數、手續費率、證交稅率 | 固定值 | 固定 1000 股、0.1425%、0.3%，回報給畫面說明用。 |
| 總成本、總未實現損益 | 數字 | 各筆加總。沒有持股時為 0。 |
| 總報酬率 | 數字或空值 | 以成本加權計算，取兩位小數。沒有持股時為空值，不是 0。 |
| 目標結算日 | 日期或空值 | 實際採用的結算日，已換成最近的交易日。未帶目標結算日時為空值。 |
| 結算總成本、結算總損益 | 數字 | 只加總有結算的持股。沒有任何一筆有結算時為 0。 |
| 結算總報酬率 | 數字或空值 | 以成本加權計算，取兩位小數。沒有任何一筆有結算時為空值。 |

**列表回應（單筆持股）**

| Field | Type/Role | Rule |
|---|---|---|
| 股票名稱 | 文字 | 取自股票目錄。 |
| 買進日、買進價、股數 | 建立時寫入的值 | 原樣回報。 |
| 買進手續費、成本 | 整數（元） | 成本等於買進價乘股數，再加買進手續費。 |
| 現價日、現價 | 日期、數字 | 該檔今日以前最後一個收盤價大於 0 的交易日及其收盤價，現價日可能早於今日。 |
| 賣出手續費、證交稅 | 整數（元） | 假設以現價賣出估算。 |
| 未實現損益 | 整數（元） | 可為負值，不夾為 0。 |
| 報酬率 | 數字 | 取兩位小數，可為負值。 |
| 結算 | 物件或空值 | 未帶目標結算日，或買進日晚於目標結算日時為空值。 |
| 結算：賣出日、賣出價 | 日期、數字 | 賣出日是目標結算日。該檔當天沒有行情時，改用之前最後一個有行情的交易日。賣出價為該日開盤價。 |
| 結算：賣出手續費、證交稅 | 整數（元） | 以賣出價計算。 |
| 結算：損益、報酬率 | 整數（元）、數字 | 可為負值，報酬率取兩位小數。 |

## 限制條件

- 買進價與股數不可由使用者輸入。要換價格只能換日期。
- 買進日與買進價寫入後不再變動。
- 同一檔股票在同一個買進日只能有一筆。重複建立會被拒絕（409），不會覆蓋舊的。以起算日建立時，比對的是系統找出的買進日：同一檔用兩個不同起算日找到同一個交易日，第二次會被拒絕。
- 指定買進日與起算日不可同時帶，同時帶或起算日格式不合法時拒絕並說明原因（400）。
- 指定買進日不得晚於今日。該日該檔沒有所取價格時直接拒絕，不會自動改用鄰近交易日。
- 起算日是唯一允許「往後找交易日」的路徑，找的範圍是該檔自己的行情，不是全市場的交易日。該檔在起算日（含）以後到今日為止都沒有行情時（含起算日晚於今日），拒絕並說明原因（400），不會建立任何持股。
- 價格為 0 的日子不算行情。
- 選開盤價時，一定要帶指定買進日或起算日。
- 目標結算日不得晚於今日。系統先檢查使用者輸入的原始日期，再換成最近的交易日。
- 目標結算日不是交易日時，換成距離最近的全市場交易日。前後等距時取較早的一天，且不晚於全市場最後一個交易日。
- 買進日晚於目標結算日的持股沒有結算，不計入結算總計，但仍列在清單中，也計入以現價計算的總計。
- 已下市的股票照常列出並計入彙總，不會消失。
- 目標結算日只是查詢條件，不會儲存。
- 沒有任何持股時，查詢仍然成功，回傳空清單。
- 清單依買進日由新到舊排序，同日依股票代號由小到大。
- 刪除時，指定的持股不存在會被拒絕。
- 這組 API 不取得外部資料，也不更動股票目錄與行情資料。

## 跨主題規則

- 建立持股時，股票代號必須存在於股票目錄（已下市也可），股票名稱也取自股票目錄（見 stock-catalog.md）。
- 買進價、現價、預設買進日、起算日之後的第一個交易日、結算賣出價，都讀取已寫入的每日行情，不會觸發抓取。價格為 0 的日子視為沒有行情（見 stock-price-ingestion.md）。
- 手續費與證交稅沿用策略回測的同一套交易成本。費率為手續費 0.1425%（買進、賣出各一次）、證交稅 0.3%（只在賣出時），各自無條件捨去到元（見 strategy-backtest.md）。
- 以開盤價建立時，買進價與策略回測的買進價同一口徑，也就是買進日開盤價。策略分頁的「加入模擬」以回測買進日建立；勾選「加入模擬以 {D} 起第一個交易日開盤買進」時改以起算日建立（見 strategy-backtest.md）。
- 「股票代號不存在」沿用策略掃描已定的同名錯誤碼與回應形狀（見 strategy-scan.md）。

## API 清單

| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/simulated-trades | 列出所有模擬持股，附即時損益、報酬率與彙總，可帶目標結算日查看結算結果。 | Live direct |
| POST | /api/simulated-trades | 以代號和買進日（或起算日）建立一筆模擬持股，買進價由系統讀取。 | Direct |
| DELETE | /api/simulated-trades/{id} | 刪除指定的一筆模擬持股。 | Direct |
