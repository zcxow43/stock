# 股票行情抓取與回補 API

負責把外部日線行情寫入系統並維護股票主檔，是整個系統唯一的資料入口，後續的指標運算與型態掃描皆只讀取此處寫入的資料，不另行對外抓取。提供每日全市場增量同步、指定多檔回補、全市場回補三種路徑，其中多檔與全市場回補是同一套流程、差別僅在目標股票清單；每一檔的回補進度都會被追蹤，中斷後能以既有進度接續，不必整批重來。系統啟動完成時會自動在背景把所有上市中股票的日線補齊到當天為止，過程不阻塞應用程式可服務的時間，也不會因外部資料源失敗而讓啟動本身失敗。同步進度另提供「最近一次真正同步成功的時間」，用來回答資料到底有多新，因此一次全部失敗的同步不會讓這個時間往前推進。

## 欄位定義

**回補作業設定**

| Field | Type/Role | Rule |
|---|---|---|
| stockIds | 回補標的（選填） | 省略或空陣列＝全部在市股票；有值則僅處理清單內股票 |
| startDate | 回補起日 | 必填；須早於實際需要的統計起日至少 250 個交易日以滿足指標暖身需求 |
| endDate | 回補迄日 | 必填 |
| resume | 是否僅補未完成部分 | 依各檔狀態（待處理／失敗）判斷；預設為否（重置後重跑） |
| catchUp | 是否為「補到迄日」語意 | 依各檔最後同步日期與迄日的差距判斷，只補落後的區間；不可與 `resume` 同時為是 |

**同步進度**

| Field | Type/Role | Rule |
|---|---|---|
| jobType | 作業類型 | 目前為每日行情回補（PRICE_BACKFILL） |
| total / pending / running / done / failed / skipped | 各狀態檔數 | 加總須等於 total |
| lastSyncedAt | 最近一次成功完成的時間 | 取狀態為「完成」的紀錄中完成時間最大值；從未成功過時為 null；一次全部失敗的同步不得使其往前推進 |
| failedItems | 失敗清單（最多 50 筆） | 含股票代號、已嘗試次數、最後錯誤訊息 |

**每日增量結果**

| Field | Type/Role | Rule |
|---|---|---|
| tradeDate | 本次同步的交易日 | 省略請求日期時取資料源當日快照日期 |
| stockCount / insertedCount / updatedCount / stockMasterUpserted | 處理筆數統計 | 反映單一外部請求涵蓋全市場後的寫入結果 |

## 限制條件

- 一律寫入原始成交價（未經除權息還原）
- 停牌或無交易日不得補零，資料源未回傳的日期完全不寫入任何列
- 所有寫入採覆寫式更新（有則更新、無則新增），同一日或同一檔重跑須為冪等操作
- 單檔一次回補的價格寫入與進度更新須落在同一交易邊界內完成，避免「資料已寫入但進度未更新」
- 逐檔回補須有可設定的請求間隔與並行上限，對過於頻繁或逾時的情況採指數退避重試
- `resume` 與 `catchUp` 不可同時為是，違反者直接拒絕
- `catchUp` 對已補到迄日（含）的股票完全不發出任何外部請求，其進度維持原狀
- `catchUp` 重新開啟一檔時，已嘗試次數歸零，不沿用先前失敗的重試次數
- 最後同步日期一律記為該次請求的迄日，不記為實際寫入最後一列的日期，以確保假日／週末落在迄日時不會被重複重抓
- 同一作業類型已有作業執行中時，新的回補請求被拒絕
- 目標區間內查無任何交易資料的標的標記為已略過，不再重試
- 啟動補齊為背景非同步執行，絕不阻塞應用程式啟動、也絕不因抓取失敗而讓啟動失敗
- 啟動補齊可由設定停用，且與手動回補共用同一並發鎖與既有回補流程，不另建一套實作
- `lastSyncedAt` 只在真正成功完成時推進，一次全部失敗的同步不得使其往前跳

## 跨主題規則

- 回補與每日增量的標的範圍限定於股票主檔中上市中的股票，主檔的存在性與上下市狀態由股票清單維護（見 stock-catalog.md）
- 回補請求中的股票代號若在股票主檔中不存在則直接拒絕，代號認定以股票主檔為準（見 stock-catalog.md）
- 每日增量順帶維護的股票代號與名稱，即為股票清單對外查詢與維護的同一份股票主檔（見 stock-catalog.md）
- 本模組寫入的日線行情是策略型態掃描運算的唯一輸入來源，掃描不另行抓取（見 strategy-scan.md）
- 系統啟動完成時會在背景自動把行情補齊到今日；此為啟動觸發而非任何網址觸發，沒有對應的請求／回應可查。行情批次全部結束後，由指標模組接續自動觸發重算（見 stock-indicator-statistics.md）

## API 清單

| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| POST | /api/stocks/sync/daily | 觸發單一交易日的全市場行情增量同步 | Direct |
| POST | /api/stocks/sync/backfill | 觸發多檔或全市場歷史行情回補（含斷點續傳與補到今日兩種語意） | Direct |
| GET | /api/stocks/sync/progress | 查詢回補作業進度與最近一次成功完成時間 | Live direct |
