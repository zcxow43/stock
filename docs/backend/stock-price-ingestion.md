# 股票行情抓取與回補 API

本 API 負責把外部交易所與歷史行情來源的股票日線資料寫入系統，是整個系統唯一的行情入口；指標計算完全依賴本模組寫入的資料，不另行對外抓取。抓取分為每日增量（每日收盤後以單一請求更新全市場）與回補（依標的清單逐檔取得歷史資料，可用於指定多檔或全市場）兩種路徑，兩者的資料寫入皆即時直接生效，不需人工審核。除了由呼叫端主動觸發外，系統在啟動完成時也會自動在背景把所有在市股票的行情補齊到當天，不需要任何人手動呼叫，也不會因為外部資料源不可用而讓應用程式啟動失敗或延後對外服務。所有寫入皆為可重複執行的更新操作（不論該筆資料先前是否已存在，都以最新資料覆蓋），確保重跑不會造成資料重複或不一致。

## 欄位定義

**股票主檔**

| Field | Type/Role | Rule |
|---|---|---|
| 股票代號 | 識別碼 | 由每日快照或回補請求提供；回補請求中含主檔內不存在的代號時，整批請求即被拒絕 |
| 股票名稱 | 描述性欄位 | 由每日全市場快照同時提供，隨每日抓取自動維護，不需獨立資料源 |
| 是否在市 | 狀態旗標 | 決定是否列入「全市場」批次範圍；請求省略指定標的時，僅處理此旗標為是的股票 |

**股票日線行情**

| Field | Type/Role | Rule |
|---|---|---|
| 交易日期 | 序列鍵，每股每日一列 | 停牌或無交易的日期不得補零，直接不產生該列 |
| 開盤／最高／最低／收盤價 | 數值，原始成交價 | 未經除權息還原；來源為含千分位符號與民國紀年的字串，須先正規化為數值與西元日期才寫入 |
| 成交量／成交金額／成交筆數 | 數值 | 隨同一來源列一併寫入 |

**同步進度**

| Field | Type/Role | Rule |
|---|---|---|
| 作業種類 | 作業分類鍵 | 行情回補固定為 `PRICE_BACKFILL` |
| 目標股票 | 該筆進度對應的標的 | 批次啟動時為目標標的建立或重設進度 |
| 進度狀態 | 待處理／執行中／完成／失敗／略過 | 依既定的狀態流轉規則推進，語意定義於進度資料本身 |
| 重試次數 | 計數 | 達上限即不再重試；補齊模式重新開啟落後標的時歸零 |
| 已處理到的日期 | 日期 | 記為該次請求的迄日本身，而非實際最後一筆資料的日期，用以支撐「補齊」的跳過判斷 |
| 最後失敗原因 | 文字 | 於進度查詢中隨失敗清單回傳，最多 50 筆 |

## 限制條件

**股票主檔**
- 代號需存在於主檔中；回補請求含未知代號時整批拒絕，不得部分成立。
- 是否在市旗標決定「全市場」範圍，非在市股票不列入全市場批次。

**股票日線行情**
- 一律使用可重複覆蓋的寫入方式，重跑同一日或同一檔須為冪等操作，且能修正資料源事後更正的值。
- 停牌或無交易日不得補零列，無資料即不寫入。
- 單檔一次回補的價格寫入與該檔進度更新須視為同一交易邊界完成，避免「資料已寫入但進度未更新」導致重跑時重複請求外部來源。

**同步進度**
- 同一作業種類同時只能有一筆作業執行中，重複觸發會被拒絕並說明原因（409）。
- 續傳僅挑選狀態為待處理或失敗、且重試次數未達上限的標的。
- 補齊依「已處理到的日期」與請求迄日的差距決定要不要抓、從哪天抓，判斷依據與續傳（依狀態判斷）不同，兩者不可同時使用，同時指定會被拒絕並說明原因（400）。
- 目標區間內查無任何交易資料的標的標記為略過，不再重試。
- 補齊重新開啟落後標的時，重試次數歸零，不沿用先前失敗的重試計數。

## 跨主題規則
- 寫入的行情一律為原始成交價，未經除權息還原，與行情資料表的欄位約定一致（見 stock-daily-price.md）。
- 斷點續傳所依據的狀態流轉語意（待處理／執行中／完成／失敗／略過）定義於進度資料表本身，本模組僅依該定義驅動批次（見 stock-sync-progress.md）。
- 指標運算模組完全以本模組寫入的日線行情為唯一輸入，不另行對外抓取；行情資料是否齊全直接決定指標能否算出（見 stock-indicator-statistics.md）。
- 系統啟動完成時，會在背景自動把行情補齊到今日；此為**啟動觸發**而非任何 HTTP 端點觸發，沒有對應的請求／回應可查，只能透過進度查詢或資料本身觀察結果。行情批次全部結束後，由另一模組接續自動觸發指標重算，本模組不涉及指標運算本身（見 stock-indicator-statistics.md）。
- 啟動補齊預設起日（2026-01-01）到今日的天數不足指標運算所需的 250 個交易日暖身，會使指標序列開頭大部分被標記為暖身而不對外呈現（見 stock-indicator-statistics.md）。

## API 清單
| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| POST | /api/stocks/sync/daily | 每日收盤後以單一請求取得全市場當日行情，並同步更新股票主檔 | Direct |
| POST | /api/stocks/sync/backfill | 對指定標的或全市場逐檔回補歷史行情，支援續傳與補齊 | Direct |
| GET | /api/stocks/sync/progress | 查詢回補或重算作業的進度統計 | Direct（查詢） |
