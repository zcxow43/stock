# MACD／KD 指標運算與兩個月統計 API

本 API 讀取行情資料自行推導 MACD 與 KD 指標（不採用任何外部指標數值），並落地遞迴中間狀態以支援每日增量推進；另提供以指定區間（預設兩個月）查詢行情與指標統計的功能，可查詢指定多檔或全市場。指標運算前會自動往前多取一段暖身期間以確保數值收斂，暖身資料不對外呈現；統計查詢除逐日序列外，會計算價格區間表現與 MACD／KD 交叉次數等摘要指標，全市場查詢基於回應量的考量僅提供摘要、不含逐日序列。

## 欄位定義

### 統計查詢參數（GET /api/stocks/statistics）

| Field | Type/Role | Rule |
|---|---|---|
| stockIds | 字串（逗號分隔），選填 | 指定欲查詢的股票代號清單，上限 50 檔；省略代表查詢全市場啟用中的股票 |
| startDate | 日期，選填 | 統計起日；省略時預設為迄日往前推兩個曆月後的第一個交易日 |
| endDate | 日期，選填 | 統計迄日；省略時取庫內最新交易日 |
| includeSeries | 布林，選填 | 是否回傳逐日序列；指定股票時預設為是，查詢全市場時只能為否，否則視為錯誤請求 |

### 個股統計項目（items[]）

| Field | Type/Role | Rule |
|---|---|---|
| stockId | 字串 | 股票代號 |
| stockName | 字串 | 股票名稱 |
| tradingDays | 整數 | 區間內實際有交易的日數；停牌日不計入 |
| warmupSufficient | 布林 | 標示該檔在統計起日之前是否已累積滿 250 個交易日的正式（非暖身）指標資料，用以提示指標數值是否已充分收斂 |
| summary | 物件或空值 | 區間摘要統計；區間內查無任何行情資料時為空 |
| series | 物件陣列，選填 | 逐日行情與指標數值；僅在查詢指定股票且允許回傳序列時提供，全市場查詢一律不含此項目 |

### 摘要區塊（summary）

| Field | Type/Role | Rule |
|---|---|---|
| firstOpen | 數值 | 區間內第一個交易日的開盤價 |
| lastClose | 數值 | 區間內最後一個交易日的收盤價 |
| highest / highestDate | 數值／日期 | 區間最高價及其發生日期 |
| lowest / lowestDate | 數值／日期 | 區間最低價及其發生日期 |
| changeAmount | 數值 | 區間期初與期末的價格變動金額 |
| changePercent | 數值 | 對應的漲跌百分比 |
| totalVolume | 數值 | 區間內總成交量 |
| avgVolume | 數值 | 區間內平均每日成交量 |
| latestDif / latestDea / latestOsc | 數值 | 區間最後一個交易日的 MACD 三項數值 |
| latestK / latestD / latestJ | 數值 | 區間最後一個交易日的 KD 三項數值 |
| macdGoldenCross / macdDeathCross | 整數 | 區間內 MACD 黃金交叉／死亡交叉發生次數 |
| kdGoldenCross / kdDeathCross | 整數 | 區間內 KD 黃金交叉／死亡交叉發生次數 |

## 限制條件

### 統計查詢

- 指定股票查詢上限 50 檔，超過即拒絕並說明原因（400）
- 省略股票代號代表查詢全市場，全市場查詢一律不含逐日序列、僅回傳摘要，避免單次回應筆數過大（約 2200 檔 × 41 個交易日）
- 全市場查詢若仍要求回傳逐日序列，視為契約層級的錯誤請求，須明確拒絕（400）而非默默截斷資料
- 查詢一律排除暖身期間的指標資料，暖身資料不對外呈現
- 指標值以完整精度參與計算，僅在回應輸出時四捨五入為四位小數
- 交叉次數以相鄰交易日比較推導，不因停牌造成的日曆間隔另做插補，且不落地儲存，屬即時運算結果
- 停牌日不計入交易日數，也不佔序列位置
- 區間內查無行情資料時仍回傳成功結果，摘要為空、序列為空

### 指標運算

- 指標一律由系統自行推導，不從任何外部服務取得指標數值
- 正確輸出兩個月指標前，必須從統計起日往前多取 250 個交易日一併運算作為暖身，暖身資料標記後不對外呈現
- 歷史不足 250 個交易日的標的仍照常運算並輸出，但須標示尚未充分收斂，不得因暖身不足而隱瞞或拒絕回應
- 全量重建與每日增量共用同一套公式：全量重建會捨棄既有指標、從暖身起點重新推導整條序列；增量僅依前一交易日狀態推進一日
- 每日增量推進時若找不到前一交易日的指標狀態，不得以初始值起算，須改標記該標的需要全量重建，避免產生未收斂的錯誤值污染後續序列
- 同一作業類型（指標重建）同時僅能有一筆批次作業執行中，重複觸發會被拒絕並說明原因（409）

## 跨主題規則

- 指標運算讀取的行情資料完全來自股票行情抓取模組寫入的結果，不另行對外抓取行情（見 stock-price-ingestion.md）
- 統計查詢與行情回補共用同一套標的選擇邏輯：提供代號清單即查詢／處理該清單，省略則代表全市場（見 stock-price-ingestion.md）
- 指標重建作業的進度查詢沿用行情回補作業的同一支查詢端點，僅以不同的作業類型區分（見 stock-price-ingestion.md）

## API 清單

| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| POST | /api/stocks/indicators/rebuild | 觸發指定股票或全市場的 MACD／KD 指標重新推導（全量重建或每日增量） | Async job |
| GET | /api/stocks/statistics | 查詢指定區間內股票的行情與指標統計，含摘要、交叉次數，可選擇性回傳逐日序列 | Direct |
