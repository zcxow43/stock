# 三大法人買賣超抓取與補齊 API

這是一個純背景的資料前置模組，沒有對外的查詢或操作端點，使用者無法直接觸發或查看它的執行狀態。它的任務是把交易所每日發布的三大法人買賣超日報，逐交易日抓取並寫入外資、投信與自營商的買進、賣出、買賣超股數，供三個法人籌碼型態（法人買賣超佔比、法人連續買超、法人買超強度排名）判定使用。是否需要抓取由資料本身回答——只要某個已有日線的交易日還沒有法人資料，就視為缺少；不另外維護一份進度紀錄。抓取動作固定跟在日線回補與每日增量成功之後自動於背景執行，不影響日線作業本身的回應內容與時間；日報較晚發布時，再按一次「同步日 K 至今日」即會補上。

## 欄位定義

**三大法人買賣超（單日、單一證券）**

| Field | Type/Role | Rule |
|---|---|---|
| 證券代號 | 字串，識別欄 | 去除前後空白後使用；只寫入 `stock` 主檔已存在的代號，主檔不存在者整列丟棄、不新增主檔列 |
| 外陸資買進／賣出／買賣超股數（不含外資自營商） | 數值，買賣超可為負（賣超） | 供法人籌碼型態判定「外資」用；外資自營商欄位不計入 |
| 外資自營商買進／賣出／買賣超股數 | 數值，買賣超可為負 | 不參與任何策略判定，僅原樣保存 |
| 投信買進／賣出／買賣超股數 | 數值，買賣超可為負 | 供法人籌碼型態判定「投信」用 |
| 自營商買賣超股數（合計／自行買賣／避險） | 數值，買賣超可為負 | 不參與任何策略判定，僅原樣保存 |
| 三大法人買賣超股數（合計） | 數值，可為負 | 僅原樣保存，不單獨用於任何判定 |
| 交易日 | 日期 | 對應日線已有資料的交易日；非交易日不會有任何列 |
| 資料來源 | 固定值 `TWSE` | 以更新或新增的方式寫入，同一日重跑時後寫入的值覆蓋先前的值 |

所有欄位以日報的欄名定位，不依欄位順序取值；數量單位為「股」，與日線成交股數同一單位，並以真實資料核對過不是「張」。

## 限制條件

- 只寫入 `stock` 主檔中已存在的代號，不論是否在市或是否為普通股；主檔不存在的代號一律丟棄，不新增主檔列。
- 單一交易日的全部列必須整批寫入或整批不寫；寫到一半中斷的日期視同尚未抓取，下次觸發會重新請求整日資料。
- 一個交易日「需要抓」的認定：該日日線已有資料，且法人買賣超該日尚無任何一列；假日或非交易日不會被請求。
- 同一時間只允許一個補齊作業執行；觸發時已有補齊在跑，本次直接略過並留下紀錄，不排隊、不重疊執行。
- 回應為「非交易日／日報尚未發布」形狀時不寫入、也不記為失敗；日報缺少必要欄名時該日整日不寫入並記錄錯誤；遇主機封鎖（`403`／`429`）立即結束本次補齊且不重試；逾時或伺服器錯誤則依既有退避策略重試，用盡後跳過該日。
- 本模組不提供任何對外端點，也不維護獨立的抓取進度表；可由設定開關整個停用（測試環境預設停用）。
- 補齊作業的任何失敗都不得影響日線回補或每日增量作業的回應內容、進度或應用程式啟動。

## 跨主題規則

- 補齊區間的起日沿用日線回補的「補齊起日」設定，不另訂一個起始日期（見 stock-price-ingestion.md）。
- 觸發時機完全依附日線作業：每次日線回補結束（含全部已是最新、未發任何外部請求就結束的情形）、以及每日增量成功寫入之後才會在背景觸發一次補齊，本身不自行排程（見 stock-price-ingestion.md）。
- 與日線全市場回補所用的交易所逐日全市場快照共用同一道請求間隔與封鎖狀態，因為兩者打的是同一個交易所主機（見 stock-price-ingestion.md）。
- 寫入的外資（不含外資自營商）與投信買賣超股數，是三個法人籌碼型態判定佔比、連續買超與強度排名的唯一資料來源；某日尚未補齊時，這些型態會把涵蓋該日的判定暫緩並以「法人資料至某日」告知（見 strategy-scan.md）。
