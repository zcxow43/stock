# 策略型態掃描 API

這組 API 讓使用者勾選一到多個型態，對指定股票與日期區間做型態偵測，並列出每個型態下命中的股票。目前共有十一個型態：五個價格型態、三個法人籌碼型態、兩個技術指標型態，以及一個均線型態（站上均線）。整體採「判定於掃描當下即時運算、不落地任何結果表」的做法：只讀既有日線與法人買賣超資料，同一批行情換一組參數就是另一組答案，所以不儲存結果。另有一支目錄查詢，回報可用型態、靈敏度與各參數的預設值與範圍，畫面一律依它產生、不寫死。每筆命中都附「進場日」，即確認完成日的下一個交易日，供回測以該日開盤價買進。回報的是型態偵測結果，不是買賣建議；永遠不可能命中的請求會直接拒絕並說明原因（400），不會受理後回零命中。

## 欄位定義

### 掃描請求（整體）

| Field | Type/Role | Rule |
|---|---|---|
| strategies | 陣列，必填 | 至少選一個型態；同一型態不得重複出現。 |
| strategies[].code | 字串，必填 | 型態代碼，共十一個：BOX_BREAKOUT、HIGHER_LOWS、RISING_SUPPORT、REBOUND、CUMULATIVE_RISE、INSTITUTIONAL_NET_RATIO、INSTITUTIONAL_CONSECUTIVE_BUY、INSTITUTIONAL_STRENGTH_RANK、MACD_GOLDEN_CROSS、KDJ_GOLDEN_CROSS、MA_BREAKOUT。未知代碼拒絕。 |
| strategies[].preset | 字串，視型態而定 | 靈敏度：嚴格／標準／寬鬆。只有箱型突破、底底高、上漲支撐三個型態必填；其餘八個型態（含站上均線）不得帶。 |
| stockIds | 字串陣列，選填 | 省略或空陣列表示掃描全部在市股票；指名的股票必須存在於股票主檔，可含已下市股票與非普通股；最多 200 檔。 |
| commonStocksOnly | 布林，選填 | 省略視為是，只掃普通股（排除 ETF、特別股、TDR）；指定股票清單時不生效。 |
| startDate | 日期，選填 | 省略時為結束日往前一個日曆月；不得晚於結束日。 |
| endDate | 日期，選填 | 省略時為今日。 |

### 各型態參數（皆放在 strategies 陣列內對應型態的項目中）

| 型態 | 欄位 | Type/Role | Rule |
|---|---|---|---|
| 箱型突破 | preset | 靈敏度 | 必填。嚴格：回看 60 根、箱高小於 5%、突破 2%、量增 2 倍、需連 2 根確認。標準：回看 20 根、箱高小於 8%、突破 1.5%、量增 1.5 倍、確認 1 根。寬鬆：回看 20 根、不驗證盤整、收盤突破箱頂即計、不驗證量能、確認 1 根。 |
| 箱型突破 | risePercent | 數值，選填 | 覆寫該靈敏度的「突破箱頂幅度」，範圍 0～20，最多一位小數；省略沿用靈敏度值；0 表示不要求幅度，不是關閉型態。 |
| 箱型突破 | requireVolume | 布林，選填 | 省略為是；為否時完全跳過量能判定。與靈敏度互不影響，也不改量增倍數；寬鬆本來就不驗證量能，送任何值結果相同。 |
| 底底高 | preset | 靈敏度 | 必填。以 5 日收盤均線為判定基準。嚴格：左右各 5 根、需 3 段遞增、每段高過 2%。標準：左右各 3 根、2 段、1%。寬鬆：左右各 2 根、2 段、高過即計。 |
| 底底高 | risePercent | 數值，選填 | 覆寫「每段遞增的最小幅度」，範圍 0～20，最多一位小數；均線平滑天數固定為 5，不開放指定。 |
| 上漲支撐 | preset | 靈敏度 | 必填。嚴格：突破前 20 日收盤高點、單日漲幅至少 5%。標準：前 10 日、3%。寬鬆：前 5 日、2%。皆要求其後守住起漲收盤，不驗證量能。 |
| 上漲支撐 | risePercent | 數值，選填 | 覆寫「單日最小漲幅」，範圍 0～20，最多一位小數。 |
| 上漲支撐 | confirmBars | 整數，選填 | 支撐必須守住的交易日數，只接受 1 或 2，省略為 2；與靈敏度互不影響。 |
| 反彈 | requireRise | 布林，選填 | 省略為是；為否時只以跌幅判定，此時不得帶反彈天數與反彈幅度。 |
| 反彈 | dropDays | 整數，選填 | 跌段回看交易日數（含谷底當日），1～90，省略為 3。 |
| 反彈 | dropPercent | 數值，選填 | 自窗口最高收盤起算的跌幅門檻，0～50，最多一位小數，省略為 10。 |
| 反彈 | riseDays | 整數，選填 | 谷底之後容許反彈達標的交易日數，1～90，省略為 1；關閉反彈漲幅時不得帶。 |
| 反彈 | risePercent | 數值，選填 | 自谷底收盤起算的反彈幅度門檻，0～50，最多一位小數，省略為 5；關閉反彈漲幅時不得帶。 |
| 累積上漲 | days | 整數，選填 | 回看交易日數（不是日曆日），1～90，省略為 20；填 1 合法，但只有漲幅門檻也為 0 時才可能命中。 |
| 累積上漲 | risePercent | 數值，選填 | 窗口內累積漲幅門檻，0～50，最多一位小數，省略為 15。 |
| 法人買賣超佔比 | investors | 字串陣列（複選），選填 | 外資（不含外資自營商）、投信的非空子集，不得重複，省略為兩者；各自獨立判定，任一方達標即命中。 |
| 法人買賣超佔比 | windowDays | 整數，選填 | 窗口交易日數（含訊號日），1～20，省略為 5。 |
| 法人買賣超佔比 | ratioPercent | 數值，選填 | 佔比門檻（%），0～100，最多一位小數，省略為 10。 |
| 法人連續買超 | investors | 字串陣列（複選），選填 | 同上。 |
| 法人連續買超 | buyDays | 整數，選填 | 連續買超交易日數（含訊號日），1～20，省略為 5；1 表示當日買超。 |
| 法人買超強度排名 | investors | 字串陣列（複選），選填 | 同上。 |
| 法人買超強度排名 | windowDays | 整數，選填 | 強度計算交易日數（含訊號日），1～20，省略為 5。 |
| 法人買超強度排名 | topN | 整數，選填 | 每一方、每個交易日取前幾名，1～50，省略為 10。 |
| MACD 黃金交叉 | fastPeriod | 整數，選填 | 短期 EMA 天數，2～50，省略為 5；必須嚴格小於長期天數。 |
| MACD 黃金交叉 | slowPeriod | 整數，選填 | 長期 EMA 天數，3～100，省略為 20。訊號線天數固定為 9，不開放指定。 |
| KDJ 黃金交叉 | jThreshold | 數值，選填 | 交叉前一交易日 J 值的上限（嚴格小於），-100～100，最多一位小數，省略為 40；KD 固定為 9,3,3，不開放指定。 |
| 站上均線 | maPeriods | 字串陣列（複選），選填 | 要判定的均線，MA5／MA20／MA60 的非空子集，不得重複，省略視為三者全選；勾選的每一條各自獨立判定，任一條達標即命中。沒有靈敏度，也不接受漲幅門檻、確認天數、量能開關。 |

| Field | Type/Role | Rule |
|---|---|---|
| startDate／endDate | 日期 | 實際採用的掃描區間。 |
| scannedStocks | 整數 | 本次實際納入掃描的股票檔數。 |
| results | 陣列 | 依請求送入的型態順序，每個型態一筆。 |
| results[].strategy | 字串 | 型態代碼。 |
| results[].（實際採用的參數） | 依型態而異 | 原樣回報實際採用值（省略時回預設值）。有靈敏度型態回靈敏度，箱型突破另回量能開關、上漲支撐另回確認天數（兩者與靈敏度並存）；累積上漲回回看天數；反彈回漲段開關、下跌天數、跌幅門檻，要求反彈漲幅時另回反彈天數與反彈幅度；三個法人型態回各自的法人與窗口／連續／名次參數；MACD 回快慢天數與固定的訊號線天數；KDJ 回 J 門檻；站上均線回所選均線清單（依 MA5→MA20→MA60 固定順序）。 |
| results[].dataThroughDate | 日期或空值 | 僅三個法人型態；法人資料實際涵蓋到的最晚交易日，區間內完全沒有法人資料時為空值；用來分辨「近日沒命中」與「近日還沒有法人資料」。 |
| results[].matchedCount | 整數 | 命中檔數，不含待確認與資料不足者。 |
| results[].items | 陣列 | 命中清單，依訊號日由新到舊、同日依股票代號升冪；每檔只回報最近一次已有進場日的命中。 |
| results[].insufficientData | 股票代號陣列 | 前置資料不足、無法判定的股票；與命中清單互斥，不算未命中。 |
| results[].pendingConfirm | 股票代號陣列 | 每一次命中都尚無進場日（確認完成日之後還沒有下一個交易日）的股票；不入命中清單、不計入命中檔數。十一個型態都可能非空。 |

## 限制條件

- 只讀不寫：判定於掃描當下由日線即時運算，不落地任何結果表；不得新增資料表或欄位，也不得動指標資料表。底底高的 5 日均線、兩個技術指標、站上均線皆屬此規則。
- 每次掃描至少選一個型態，同一型態不得重複；型態最多十一個。
- 靈敏度只有箱型突破、底底高、上漲支撐三個型態有且必填；其餘八個型態（含站上均線）不得帶靈敏度。
- 漲幅門檻上限逐型態認定：箱型突破、底底高、上漲支撐為 0～20；反彈、累積上漲為 0～50，皆最多一位小數。三個法人型態、兩個技術指標型態與站上均線不接受此欄位，帶了就拒絕（400）。
- 參數只適用於指定型態，帶到不適用的型態一律拒絕，不靜默忽略：法人參數（法人、窗口天數、佔比、連續天數、名次）、MACD 天數、KDJ 門檻、均線選擇；確認天數只給上漲支撐；量能開關只給箱型突破；反彈參數只給反彈；回看天數只給累積上漲。
- 反彈關閉「要求反彈漲幅」後，不得再帶反彈天數與反彈幅度；自相矛盾的請求視為錯誤。
- MACD 短期天數必須嚴格小於長期天數（其一省略時以預設值比較）；各欄自身範圍錯誤優先回報。
- 複選參數（法人、均線）不得為空、不得重複、不得含選項以外的值。
- 布林欄位嚴格解析：字串形式的「false」或數字 0 不得被當成否；無法解析的請求本體拒絕（400）。
- 掃描母體：省略股票清單時為全部在市股票，預設只留普通股（代號恰為 4 位數字且首字元非 0）；指名股票時不套用普通股篩選；上限 200 檔，超過即拒絕而非截斷；指名的股票必須存在。普通股篩選只影響掃描母體，不改動股票主檔。
- 區間：起日不得晚於迄日；省略時為今日往前一個日曆月。
- 前置資料取自起日之前：箱型突破與上漲支撐為回看根數；底底高為擺動根數加 4；反彈為（下跌天數−1＋反彈天數），關閉反彈漲幅時只需（下跌天數−1）；累積上漲為（天數−1）；法人型態為（窗口或連續天數−1），日線與法人資料皆須涵蓋；兩個技術指標最多讀 250 個交易日暖身；站上均線為所選均線天數的最大值。
- 進場日所需資料取自迄日之後：其餘十個型態最多多讀 1 個交易日，上漲支撐最多多讀（確認天數＋1）個；法人資料只讀到迄日。
- 資料不足歸入「資料不足」清單，不算未命中；技術指標型態在訊號日之前需至少 100 個交易日日線才判定（不以 250 根為門檻）；站上均線在區間內沒有任何可判定日者歸入資料不足。
- 交易日一律依該檔相鄰日線認定，停牌缺列不計，不做插補、不以日曆日推算。
- 沒有下一個交易日時，該次命中沒有進場日，不進命中清單；若同一檔有較早且已有進場日的命中，以那一次回報，且不列入待確認。
- 行情與法人資料必須批次讀取，不得逐檔查詢；技術指標與站上均線不另讀資料，兩個技術指標同時送出時共用同一份行情；三個法人型態共用同一份法人讀取結果。
- 法人型態：窗口內任一日法人資料尚未抓取，該檔在該訊號日不判定；已抓取但該檔無資料列視為當日買賣超 0；比率一律用「合計除以合計」，判定與排名使用未四捨五入的原值；成交量為 0 時不成立。
- 法人買超強度排名只讓淨買超者參與，名次在本次掃描母體內、每個交易日各自計算，外資與投信各自取前 N 名，同強度依股票代號升冪。
- 兩個技術指標型態與底底高／站上均線所用公式與均線定義，須與系統既有指標運算共用同一套實作，不得另寫一份；站上均線與底底高的 5 日均線為同一條收盤均線，全系統只有這一種均線。
- 站上均線：前一日收盤小於或等於均線、當日收盤大於均線才算站上（貼線不算）；不做量能與站穩確認；三條均線共用同一組參數。
- 底底高與箱型突破（嚴格）的進場日仍早於其真正可被判定的時點（已知限制，本次不調整），不得在文件或畫面上將這兩個型態的回測數字描述為「無未來資訊」。
- 回應、畫面與文件一律使用「命中／訊號／型態」用語，不得出現「建議買進」「推薦」等暗示操作的措辭。

## 跨主題規則

- 每筆命中的進場日由本掃描回報，回測以該日開盤價買進；回測端不得自行推算進場日，否則等於在掃描之外再寫第二份型態規則。淨賣超方向的法人命中同樣會進入回測。（見 strategy-backtest.md）
- 掃描所用日線來自行情寫入主題：行情自 2026-01-01 起累積，天數超過該檔可用行情者列入資料不足；歷史列成交量系統性偏低，會使法人佔比與強度被高估約一成多，三個法人型態不做修正，須靠該主題的一次性全市場重補消除。（見 stock-price-ingestion.md）
- 三個法人型態使用三大法人買賣超日報：口徑為外陸資（不含外資自營商）與投信，資料源只列出當日有交易的證券（故已抓取日無列視為 0），日報收盤後才發布，因此進場日為訊號日的下一個交易日，且最新一兩個交易日可能尚無資料。（見 institutional-trade-ingestion.md）
- 兩個技術指標型態沿用指標統計主題的黃金交叉定義（以相鄰兩日比較）與 250 根完全收斂的實測結論，公式與初始值以指標資料表規格為準，僅放寬 MACD 快慢 EMA 天數可由呼叫端指定；訊號日與指標運算須一致，避免日 K 圖與策略命中的交叉日對不起來。預設 5／20 與日 K 圖的 12／26／9 不同，要一致須明確指定。（見 stock-indicator-statistics.md）
- 站上均線的 5 日均線定義與底底高共用；掃描母體的普通股判斷沿用股票母體匯入主題的「只收普通股」定義，兩處須共用同一個判斷。（見 stock-universe-import.md）
