# 策略型態掃描 API

在既有日線行情上做型態偵測，找出哪些股票在指定區間內出現「箱型突破」或「底底高」的價格型態。整個查詢採即時運算、完全不落地任何結果，因為判定結果完全由使用者選擇的靈敏度參數決定，若把結果存起來會立刻衍生出「這筆結果是用哪組參數算出來的」這類難以維護的問題，而重新計算的成本原本就很低。每個型態都提供三段靈敏度可選，靈敏度只調整命中的門檻高低，不改變判定邏輯本身。系統會把「因前置資料不足而無法判定」與「判定過但沒有出現型態」分開回報，讓使用者清楚知道兩者的差異。所有輸出一律以型態偵測或訊號描述，不以任何形式建議買進賣出。

## 欄位定義

**策略定義**

| Field | Type/Role | Rule |
|---|---|---|
| code | 策略代碼（列舉） | 值為 BOX_BREAKOUT（箱型突破）或 HIGHER_LOWS（底底高），由後端固定定義 |
| name | 策略名稱 | 對應 code 的中文顯示名稱 |
| presets | 靈敏度預設清單 | 每個策略固定提供 STRICT／STANDARD／LOOSE 三段 |
| presets[].code | 靈敏度代碼（列舉） | STRICT／STANDARD／LOOSE，只影響判定門檻，不影響判定邏輯本身 |
| presets[].name | 靈敏度名稱 | 嚴格／標準／寬鬆 |
| presets[].description | 靈敏度說明 | 依規格的參數表產生，前端不得另行寫死說明文字 |

**掃描請求（不落地）**

| Field | Type/Role | Rule |
|---|---|---|
| strategies | 欲執行的策略與靈敏度組合 | 至少一筆；同一策略代碼不得於同一次請求重複出現 |
| strategies[].code / preset | 策略代碼／靈敏度代碼 | 皆須為已定義的合法值 |
| stockIds | 掃描標的（選填） | 省略或空陣列＝全部在市股票；有值時可包含已下市股票；上限 200 檔 |
| startDate / endDate | 掃描區間（選填） | 省略時區間為「今日往前一個日曆月～今日」 |

**命中結果（即時運算，不落地）**

| Field | Type/Role | Rule |
|---|---|---|
| strategy / preset | 對應之策略與靈敏度 | 依請求送入順序逐一回報一筆 |
| matchedCount | 命中檔數 | 等於 items 筆數 |
| items[].stockId / stockName | 命中股票 | 依 signalDate 新到舊排序，同日依代號升冪 |
| items[].signalDate | 命中日期 | 該檔在區間內最近一次命中之交易日，多次命中僅回報最近一次 |
| items[].detail | 判定明細 | 依策略而異：箱型突破含箱頂／箱底／突破收盤／突破幅度／量能倍數；底底高含遞增低點序列 |
| insufficientData | 資料不足清單 | 前置資料不足以完成判定的股票代號；與 items／matchedCount 互斥 |
| pendingConfirm | 待確認清單 | 僅箱型突破且需二日確認時使用，已突破但確認日尚未到 |

## 限制條件

- 同一次請求至少選一個策略，且不得重複同一策略代碼
- 靈敏度僅能是既定的三段之一，門檻不可由呼叫端自訂
- 掃描標的上限 200 檔，超過即直接拒絕，而非默默截斷
- 省略 `stockIds` 時僅涵蓋在市股票；明確指定時允許包含已下市股票
- 判定所需的前置資料（回看根數／擺動根數）取自區間起日之前，只用於判定、不算作命中
- 「前置資料不足」與「判定過但未命中」須分開回報，不可混為一談
- 型態判定僅比較相鄰交易日，不因停牌造成的日曆間隔做任何插補
- 掃描結果完全不落地儲存，相同參數重新呼叫即重新計算
- 回應用語一律以命中／訊號／型態表述，不得出現「建議」「推薦」等操作性字眼

## 跨主題規則

- 掃描標的範圍與代號存在性檢查依附於股票主檔（見 stock-catalog.md）
- 掃描讀取的日線行情完全由每日增量與回補流程寫入，本模組不自行對外抓取（見 stock-price-ingestion.md）
- 相鄰交易日的判定基準需與統計模組的交叉判定規則一致，不得各自定義（見 stock-indicator-statistics.md）

## API 清單

| Method | Path | 用途 | 送審分類 |
|---|---|---|---|
| GET | /api/strategies | 取得可用策略與各策略的靈敏度說明 | Live direct |
| POST | /api/strategies/scan | 依指定策略與靈敏度即時掃描並回傳命中清單 | Live direct |
