# domain — 本專案的客製內容

`.claude/` 是跨專案通用的工程工具，且未進版控。
`domain/` 是這個專案專屬的業務內容，進版控。業務知識不放 `.claude/`。

| 資料夾 | 放什麼 |
|---|---|
| `specialist/` | 我方定義：參數、門檻、措辭規則。只寫猜不到的決定，不寫通用知識。 |
| `tasks/` | 本專案專屬的作業指示。不吃 slash，要執行就指名檔案路徑。 |

## 關鍵字路由

`/spec` 命中關鍵字就完整讀對應檔案，並把定義寫成 spec 的 Acceptance Criteria。新增檔案要同時加一列。

| 關鍵字 | 檔案 |
|---|---|
| 箱型、突破、底底高、型態、訊號、交叉、背離、技術分析 | `specialist/technical-analysis.md` |

## 兩條規則

1. `【待定】` 的值由使用者決定，`/spec` 必須先問，不得自行套預設值。
2. 內容必須固化進 spec —— `/dev` 的 agent 只拿得到 spec 內容，不會來讀 `domain/`。
